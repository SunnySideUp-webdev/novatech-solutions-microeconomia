# NovaTech Solutions

Sitio corporativo y presentación académica del Proyecto Final Aplicado de Microeconomía de la Universidad Mariano Gálvez de Guatemala.

## Contenido

- Presentación de la empresa, misión y visión.
- Seis servicios tecnológicos.
- Planes y precios propuestos.
- Diagnóstico interactivo con recomendación simulada.
- Proceso de atención al cliente.
- Caso aplicado de EcoWash con panel demostrativo.
- Resumen académico y descarga del documento completo.
- Video de exposición integrado desde YouTube.

## Ver el sitio

Abre `dist/index.html` en un navegador. El proyecto utiliza HTML, CSS y JavaScript sin dependencias ni proceso de compilación.

## Estructura

```text
dist/
├── assets/
│   └── Proyecto-Final-NovaTech-Solutions.pdf
├── app.js
├── caso-ecowash.html
├── index.html
└── styles.css
```

## Estado

Versión funcional con el proyecto, el caso aplicado y el video grupal integrados.

> Este sitio es una demostración académica. Los precios, costos y escenarios económicos no representan ventas realizadas.
